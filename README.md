# Java_Programming
Java Programming - Logic Building Batch

📝 Description

This repository tracks my progressive journey in Java Programming through the Logic Building batch. It contains daily classwork practice programs and structured assignment solutions. The codebase evolves from foundational programming concepts (loops, conditions, basic logic) to Object-Oriented Programming (OOP) principles, classes, objects, and advanced problem-solving.

Author: Abhishek Mahesh Khedkar

🚀 How to Compile and Run

All programs are written in standard Java and can be compiled and executed using the Java Development Kit (JDK) via the terminal or command prompt.

Open your terminal and navigate to the specific folder (either a Classwork day or a specific Assignment):

cd Classwork/Day_01
# OR
cd Assignments/Assignment_1


Compile the Java program using javac (replace Filename.java with the actual file name):

javac Filename.java


Run the generated class file using java (do not add the .class extension):

java Filename
